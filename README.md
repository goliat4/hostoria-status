# Status usług Hostoria

Publiczna strona statusu hostingu Hostoria (Bartecki Group Sp. z o.o.), oparta na [Upptime](https://upptime.js.org). Monitorowane co 5 minut: strona hostoria.pl, panel klienta, webmail, SMTP i IMAP. Strona: https://status.hostoria.pl

Konfiguracja: `.upptimerc.yml`. Historia i wykresy są generowane automatycznie przez GitHub Actions.
